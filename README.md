# Hexlet Chat

A simplified Slack-like chat application.

### Hexlet tests and linter status:
[![Actions Status](https://github.com/erumel/fullstack-python-project-12/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/erumel/fullstack-python-project-12/actions)

## Technologies

- **Frontend:** React 19, Redux Toolkit, React Router 7, Formik, Yup, Socket.IO
- **UI:** React Bootstrap, React Toastify
- **Bundler:** Vite
- **Error monitoring:** Rollbar
- **Internationalization:** i18next
- **Deploy:** Render

## Installation and Setup

```bash
# Clone the repository
git clone https://github.com/erumel/fullstack-python-project-12.git
cd fullstack-python-project-12

# Install dependencies
make install

# Build the frontend
make build

# Start the server
make start

# Start in development mode
make dev
